# AL-STRUCT-INVALID-DIRECTIVE

**Severity:** error  
**Category:** structural

## Description

Invalid value '${value}' for '${directiveName}' directive

## Remediation

Use one of the allowed values: ${allowedValues}

## Examples

### Invalid

```archlex
direction: diagonal
```

### Valid

```archlex
direction: LR
```
