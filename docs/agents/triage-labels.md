# Triage Label Vocabulary

This file maps the five canonical triage roles to the label strings used in this repository's issue tracker.

| Role | Label |
|------|-------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

## Usage

The `triage` skill applies these labels when moving issues through triage roles. If your tracker already uses different label names (e.g., `bug:triage` instead of `needs-triage`), edit this table so the skill applies existing labels instead of creating duplicates.
