# Getting Started

## Install

Install ArchLex and all supported provider packages with npm:

```bash
npm install @archlex/core @archlex/aws @archlex/gcp @archlex/k8s
```

Use pnpm if your project uses it:

```bash
pnpm add @archlex/core @archlex/aws @archlex/gcp @archlex/k8s
```

## Requirements

- Node.js 22.0.0 or later
- A browser with ES2022 support for browser applications

## Register Providers

Create one ArchLex instance with AWS, Google Cloud, and Kubernetes:

```typescript
import {
  awsProvider,
  createArchLex,
  gcpProvider,
  k8sProvider,
} from "@archlex/core";

const archlex = createArchLex({
  providers: [awsProvider(), gcpProvider(), k8sProvider()],
});
```

## Write a Diagram

Select one provider in each source and connect its resources:

```typescript
const source = `
direction LR
provider aws
validation normal

alb -[routes]-> ecs
ecs -[writes]-> rds
`;
```

Use `provider gcp` with Google Cloud resource IDs or `provider k8s` with
Kubernetes resource IDs. You can keep the shared provider registration.

## Render SVG

```typescript
const result = await archlex.render(source);

for (const diagnostic of result.diagnostics) {
  console.warn(diagnostic.code, diagnostic.message);
}

console.log(result.svg);
```

In a browser, assign `result.svg` to a container that you control. Treat the
diagnostics array as part of the render result so your interface can point users
to invalid resources or relationships.

## Open the Playground

Use the [interactive playground](/playground) to edit source and inspect the SVG
