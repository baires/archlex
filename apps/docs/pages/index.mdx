# ArchLex Documentation

ArchLex turns text architecture definitions into accessible SVG diagrams. One
language covers AWS, Google Cloud, and Kubernetes. Agents write it. Humans can
still read it.

## Start here

1. [Use with AI agents](/guides/agents) — install the skill, connect MCP, ask for a diagram.
2. Open the [playground](https://playground.archlex.dev) to edit the source yourself.
3. [Getting Started](/getting-started) walks through the TypeScript API when you want to embed ArchLex.

## Supported Providers

| Provider | Directive | Package | Example resources |
| --- | --- | --- | --- |
| AWS | `provider aws` | `@archlex/aws` | Lambda, ECS, RDS, S3 |
| Google Cloud | `provider gcp` | `@archlex/gcp` | Cloud Run, GKE, Cloud SQL, BigQuery |
| Kubernetes | `provider k8s` | `@archlex/k8s` | Deployment, Service, Ingress, StatefulSet |

## First Render

Install the core and provider packages:

```bash
npm install @archlex/core @archlex/aws @archlex/gcp @archlex/k8s
```

Register one shared provider set. Each source selects its provider with the `provider` directive.

```typescript
import {
  awsProvider,
  createArchLex,
  gcpProvider,
  k8sProvider,
} from "@archlex/core";

const archlex = createArchLex({
  providers: [awsProvider(), gcpProvider(), k8sProvider()],
});

const result = await archlex.render(`
direction LR
provider aws
validation normal

alb -[routes]-> ecs
ecs -[writes]-> rds
`);

console.log(result.svg);
```
